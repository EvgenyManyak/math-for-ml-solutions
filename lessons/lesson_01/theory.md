# Урок 01. Векторы и операции над ними

> **Зачем это нужно:** любые данные в ML — это векторы. Картинка 28×28 — вектор из 784 чисел. Пользователь — вектор предпочтений. Слово — вектор эмбеддинга. Не понимая операций над векторами, вы не понимаете, что происходит внутри любой модели.

---

## 1. Что такое вектор

В ML вектор — это просто упорядоченный набор чисел. Точка. Без философии про «направленные отрезки».

```
x = [3.0, -1.5, 2.7, 0.0, 5.1]   # вектор размерности 5
```

Размерность вектора — количество чисел в нём. В реальных задачах размерности от 2 (точка на плоскости) до 4096 (эмбеддинг от BERT) и больше.

```python
import numpy as np
x = np.array([3.0, -1.5, 2.7, 0.0, 5.1])
print(x.shape)   # (5,)
print(x.ndim)    # 1 — одномерный массив
```

## 2. Сложение и умножение на скаляр

**Сложение векторов** — поэлементно. Размерности должны совпадать.

$$ a + b = (a_1 + b_1, a_2 + b_2, \dots, a_n + b_n) $$

**Умножение на скаляр** — каждый элемент умножается на число.

$$ \alpha \cdot a = (\alpha a_1, \alpha a_2, \dots, \alpha a_n) $$

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(a + b)        # [5 7 9]
print(3 * a)        # [3 6 9]
print(a - 2 * b)    # [-7 -8 -9]
```

**Интуиция:** сложение — это «склейка» движений. Если `a` — это «шаг на восток на 3 метра», а `b` — «шаг на север на 4 метра», то `a + b` — это диагональный шаг.

---

## 3. Скалярное произведение (dot product)

Самая важная операция в ML. Без преувеличения.

$$ a \cdot b = \sum_{i=1}^{n} a_i b_i = a_1 b_1 + a_2 b_2 + \dots + a_n b_n $$

Результат — **одно число** (скаляр).

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# Три эквивалентных способа
print(np.dot(a, b))   # 32
print(a @ b)          # 32 — оператор @
print((a * b).sum())  # 32
```

**Где это в ML:**
- Один нейрон вычисляет `w · x + b` — это скалярное произведение весов и входа.
- В attention вы считаете `Q · K` — близость запроса к каждому ключу.
- В рекомендательных системах user · item даёт оценку.

---

## 4. Норма вектора (длина)

**Евклидова норма** (L2) — длина вектора:

$$ \|a\|_2 = \sqrt{a_1^2 + a_2^2 + \dots + a_n^2} = \sqrt{a \cdot a} $$

```python
a = np.array([3, 4])
print(np.linalg.norm(a))     # 5.0 — теорема Пифагора
print(np.sqrt(a @ a))         # 5.0 — то же самое руками
```

**L1 норма** — сумма модулей:

$$ \|a\|_1 = |a_1| + |a_2| + \dots + |a_n| $$

```python
print(np.linalg.norm(a, ord=1))   # 7.0
```

L1 даёт разреженные решения (Lasso), L2 — гладкие (Ridge). Это вы увидите в регуляризации.

## 5. Косинус угла между векторами

Самая частая метрика похожести в ML:

$$ \cos(\theta) = \frac{a \cdot b}{\|a\| \cdot \|b\|} $$

Значение от -1 до 1. Близко к 1 — векторы «смотрят в одну сторону», 0 — перпендикулярны, -1 — противоположны.

```python
def cosine(a, b):
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

a = np.array([1, 0])
b = np.array([1, 1])
print(cosine(a, b))   # ≈ 0.707 — угол 45°
```

**Где это в ML:** поиск похожих документов, рекомендации, семантический поиск, кластеризация эмбеддингов.
