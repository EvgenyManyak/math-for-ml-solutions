# Урок 03. Собственные числа и SVD

> **Зачем это нужно:** PCA, спектральная кластеризация, рекомендательные системы, latent semantic analysis — всё это про разложение матриц на компоненты. SVD — самая полезная операция в прикладной линейной алгебре.

---

## 1. Собственные числа и векторы

Вектор `v` — собственный для матрицы `A`, если умножение на `A` только растягивает его, не меняя направления:

$$ A v = \lambda v $$

`λ` — собственное число (во сколько раз растянули).

```python
import numpy as np
A = np.array([[2, 0], [0, 3]])
eigvals, eigvecs = np.linalg.eig(A)
print(eigvals)   # [2. 3.]
print(eigvecs)   # столбцы — собственные векторы
```

**Интуиция:** если применять `A` много раз подряд, длинное направление вытянется ещё сильнее. Это объясняет, почему градиенты в RNN взрываются/затухают — там умножается одна и та же матрица.

## 2. Спектральное разложение

Для симметричной матрицы существует разложение:

$$ A = Q \Lambda Q^T $$

где `Q` — ортогональная матрица собственных векторов, `Λ` — диагональ из собственных чисел.

```python
A = np.array([[4, 1], [1, 3]])    # симметричная
eigvals, Q = np.linalg.eigh(A)    # eigh — для симметричных, быстрее и точнее
Lambda = np.diag(eigvals)
reconstructed = Q @ Lambda @ Q.T
print(np.allclose(A, reconstructed))   # True
```

---

## 3. SVD — главное оружие

Сингулярное разложение работает для **любой** матрицы (не обязательно квадратной):

$$ A = U \Sigma V^T $$

- `U` — ортогональная (m × m), левые сингулярные векторы.
- `Σ` — диагональная (m × n) с неотрицательными числами по убыванию — сингулярные значения.
- `V^T` — ортогональная (n × n), правые сингулярные векторы.

```python
A = np.random.randn(5, 3)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
print(U.shape, s.shape, Vt.shape)   # (5,3) (3,) (3,3)

# Восстанавливаем
A_back = U @ np.diag(s) @ Vt
print(np.allclose(A, A_back))   # True
```

**Интуиция:** любое линейное преобразование = поворот → растяжение по осям → ещё один поворот. `V^T` поворачивает, `Σ` растягивает, `U` поворачивает.

## 4. Низкоранговое приближение

Хотите сжать матрицу — оставьте только `k` самых больших сингулярных чисел. Это лучшее приближение ранга `k` (теорема Эккарта–Янга).

```python
def low_rank(A, k):
    U, s, Vt = np.linalg.svd(A, full_matrices=False)
    return U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]

# Сжатие изображения
from PIL import Image
img = np.array(Image.open('photo.jpg').convert('L'), dtype=float)
img_k = low_rank(img, k=50)   # приближение ранга 50
```

**Где это в ML:** сжатие моделей (LoRA — это буквально low-rank update!), рекомендации, очистка от шума.

## 5. PCA через SVD

PCA (Principal Component Analysis) — главные компоненты. Находит направления максимальной дисперсии.

Алгоритм за 5 строк:

```python
def pca(X, k):
    X_centered = X - X.mean(axis=0)         # центрируем
    U, s, Vt = np.linalg.svd(X_centered, full_matrices=False)
    components = Vt[:k]                      # топ-k главных компонент
    X_reduced = X_centered @ components.T    # проекция данных
    return X_reduced, components

# Пример: уменьшить размерность с 100 до 2
X = np.random.randn(1000, 100)
X_2d, comps = pca(X, k=2)
print(X_2d.shape)   # (1000, 2)
```

Этим вы заменяете 5 страниц теории про ковариационные матрицы. SVD делает всё сам.

## 6. Связь спектрального разложения и SVD

Для симметричной `A`: собственные числа = сингулярные значения, собственные векторы = сингулярные.

Для произвольной `A`: сингулярные значения `A` = квадратные корни из собственных чисел `A^T A`.

```python
A = np.random.randn(5, 3)
_, s, _ = np.linalg.svd(A)
eigvals = np.linalg.eigvalsh(A.T @ A)
print(np.sort(s**2)[::-1])
print(np.sort(eigvals)[::-1])
# Должны совпадать
```
