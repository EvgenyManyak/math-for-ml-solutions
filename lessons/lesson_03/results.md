# 📚 Урок 3: Собственные числа и SVD
Практическое освоение методов линейной алгебры для машинного обучения
8 заданий из курса по сингулярному разложению (SVD) и его приложениям. Каждое задание демонстрирует ключевую концепцию: от теоретических основ до реальных задач (сжатие изображений, рекомендации, NLP).

## ✅ Обзор заданий
### Задание 1: Свой PCA
  * Реализация PCA двумя способами:
    * Через собственные векторы ковариационной матрицы (np.linalg.eigh)
    * Через SVD (np.linalg.svd)
### ✅ Результат: Методы эквивалентны с точностью до знака компонент.

### Задание 2: Сжатие изображения
  * SVD-сжатие изображения 1000×1000:
    * Графики ошибки восстановления (MSE) и размера данных
    * Визуальная оценка качества при k = [5, 10, 50, 100, 500]
### ✅ Результат: При k=50 изображение визуально неотличимо от оригинала.

### Задание 3: Eigenfaces
  * PCA на датасете лиц LFW (k=50):
    * Визуализация первых 16 компонент как «средних лиц»
### ✅ Результат: Компоненты отражают глобальные особенности (освещение, контуры).

### Задание 4: Степенной метод
  * Итеративный поиск максимального собственного числа:
    * Сравнение с np.linalg.eig на ковариационной матрице Iris
### ✅ Результат: Сходимость к доминирующему собственному числу (λ ≈ 4.228).

### Задание 5: Рекомендации через SVD
  * Прогнозирование оценок фильмов на MovieLens-100k:
    * Заполнение пропусков через усечённое SVD (k=20)
    * Оценка качества через MAE
### ✅ Результат: MAE ≈ 0.23 — высокая точность предсказаний.

### Задание 6: LSA на текстах
  * Анализ 100 документов через Latent Semantic Analysis:
    * TF-IDF → SVD (k=10) → поиск близких документов
### ✅ Результат: Тематически схожие документы группируются в LSA-пространстве.

### Задание 7: Условное число
  * Исследование обусловленности матриц:
    * Генерация матриц с заданным условным числом
    * Анализ роста ошибки при решении систем с шумом
### ✅ Результат: Ошибка растёт линейно с условным числом (log-log график).

### Задание 8: TruncatedSVD vs PCA
  * Сравнение методов на разреженных данных (TF-IDF):
    * TruncatedSVD работает напрямую с разреженными матрицами
    * PCA требует центрирования и плотной матрицы
### ✅ Результат: Для текстовых данных предпочтителен TruncatedSVD.

## 💡 Ключевые выводы курса
 * SVD — универсальный инструмент: применим для сжатия, рекомендаций, NLP.
 * Центрирование критично: PCA требует его, но это нарушает разреженность → используйте TruncatedSVD для текстов.
 * Обусловленность влияет на стабильность: плохо обусловленные системы чувствительны к шуму.
 * k-компоненты — баланс качества и сложности: оптимальное k зависит от задачи (визуальное качество vs размер данных).
