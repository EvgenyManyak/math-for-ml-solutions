### 1. Цель задания
**Цель:** Научиться визуально и аналитически различать фундаментальные дискретные и непрерывные распределения. Понять, как параметры (вероятность успеха, число испытаний, интенсивность, среднее и дисперсия) влияют на форму, сдвиг и разброс графиков. 
**Ожидаемый результат:** Построенные теоретические графики функций массы (PMF) для дискретных и функций плотности (PDF) для непрерывных распределений для нескольких наборов параметров, без использования готовых функций из вероятностных библиотек (только базовая математика).

### 2. Терминология
*   **Случайная величина (СВ):** Переменная, значение которой зависит от исхода случайного события.
*   **Дискретное распределение:** СВ принимает конечное или счетное множество значений (например, $0, 1, 2, \dots$).
*   **PMF (Probability Mass Function / Функция вероятности):** Функция, которая ставит в соответствие каждому возможному дискретному значению точную вероятность того, что СВ примет это значение: $P(X = k)$. Сумма всех вероятностей всегда равна 1.
*   **Непрерывное распределение:** СВ принимает любое значение на континууме (например, отрезке или всей числовой прямой). Вероятность принятия конкретного точечного значения равна 0.
*   **PDF (Probability Density Function / Плотность вероятности):** Функция $f(x)$, описывающая плотность вероятности в точке. Вероятность попадания в интервал вычисляется как интеграл: $P(a \le X \le b) = \int_a^b f(x)dx$. Площадь под кривой PDF всегда равна 1. Значение самой функции $f(x)$ может быть больше 1.
*   **Носитель распределения (Support):** Множество значений, на которых вероятность (или плотность) строго больше нуля.

### 3. Математическая идея
Вам нужно реализовать формулы пяти распределений. Так как в условии не заданы конкретные параметры, **выбираем следующую разумную трактовку**: для каждого распределения возьмем 2-3 набора параметров, чтобы показать изменение формы. Для дискретных распределений будем использовать небольшие значения (чтобы избежать переполнения при вычислении факториалов).

**1. Распределение Бернулли (Дискретное, PMF)**
Описывает один эксперимент с двумя исходами (успех/неудача).
*   Параметры: $p \in [0, 1]$ — вероятность успеха.
*   Носитель: $k \in \{0, 1\}$.
*   Формула: $P(X=k) = p^k (1-p)^{1-k}$
    *   При $k=0$: $P(X=0) = 1-p$
    *   При $k=1$: $P(X=1) = p$

**2. Биномиальное распределение (Дискретное, PMF)**
Описывает число успехов в серии из $n$ независимых испытаний Бернулли.
*   Параметры: $n \in \mathbb{N}$ (число испытаний), $p \in [0, 1]$ (вероятность успеха в одном испытании).
*   Носитель: $k \in \{0, 1, \dots, n\}$.
*   Формула: $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$
*   Где биномиальный коэффициент: $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ — число способов выбрать $k$ успехов из $n$ испытаний.

**3. Нормальное распределение (Непрерывное, PDF)**
Описывает непрерывные данные, подверженные влиянию множества мелких случайных факторов.
*   Параметры: $\mu \in \mathbb{R}$ (математическое ожидание, центр колокола), $\sigma > 0$ (стандартное отклонение, ширина колокола).
*   Носитель: $x \in (-\infty, +\infty)$. На практике строим на отрезке $[\mu - 4\sigma, \mu + 4\sigma]$.
*   Формула: $f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$

**4. Распределение Пуассона (Дискретное, PMF)**
Описывает число событий, происходящих за фиксированное время/площадь, если события происходят независимо с постоянной средней интенсивностью.
*   Параметры: $\lambda > 0$ (ожидаемое число событий за интервал).
*   Носитель: $k \in \{0, 1, 2, \dots\}$. Для графика берем $k$ до тех пор, пока вероятности не станут пренебрежимо малыми (например, до $k \approx \lambda + 4\sqrt{\lambda}$).
*   Формула: $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$

**5. Экспоненциальное распределение (Непрерывное, PDF)**
Описывает время ожидания между событиями Пуассона. Обладает свойством отсутствия памяти.
*   Параметры: $\lambda > 0$ (интенсивность, обратная величина к среднему времени ожидания: $\text{Mean} = 1/\lambda$).
*   Носитель: $x \ge 0$.
*   Формула: $f(x) = \lambda e^{-\lambda x}$ для $x \ge 0$ (и $0$ для $x < 0$).

### 4. Алгоритм решения
Ниже представлен абстрактный псевдокод. Ваша задача при программировании — переложить эту логику на ваш язык, используя базовые массивы и математические функции (возведение в степень, экспоненту, факториал/гамма-функцию), без обращения к готовым распределениям.

```text
// Вспомогательная функция для биномиального коэффициента
ФУНКЦИЯ бином_коэф(n, k):
    // Защита от больших чисел: можно вычислять через логарифмы или рекурсивно
    RETURN факториал(n) / (факториал(k) * факториал(n - k))

// 1. БЕРНУЛЛИ
массив_p = [0.2, 0.5, 0.8]
ДЛЯ КАЖДОГО p ИЗ массив_p:
    X_bern = [0, 1]
    Y_bern = [1 - p, p]
    ПОСТРОИТЬ столбчатый график (X_bern, Y_bern) с подписью "p = " + p

// 2. БИНОМИАЛЬНОЕ
массив_параметров_бин = [(10, 0.5), (20, 0.2), (20, 0.8)]
ДЛЯ КАЖДОЙ ПАРЫ (n, p) ИЗ массив_параметров_бин:
    X_bin = ЦЕЛОЧИСЛЕННЫЙ МАССИВ ОТ 0 ДО n
    Y_bin = ПУСТОЙ МАССИВ
    ДЛЯ КАЖДОГО k ИЗ X_bin:
        comb = бином_коэф(n, k)
        prob = comb * (p^k) * ((1 - p)^(n - k))
        ДОБАВИТЬ prob В Y_bin
    ПОСТРОИТЬ столбчатый график (X_bin, Y_bin)

// 3. НОРМАЛЬНОЕ
массив_параметров_норм = [(0, 1), (0, 2), (5, 1)]
ДЛЯ КАЖДОЙ ПАРЫ (mu, sigma) ИЗ массив_параметров_норм:
    // Создаем плотную сетку из, например, 1000 точек
    X_norm = ЛИНЕЙНОЕ ПРОСТРАНСТВО ОТ (mu - 4*sigma) ДО (mu + 4*sigma), ШАГ=1000
    Y_norm = ПУСТОЙ МАССИВ
    ДЛЯ КАЖДОГО x ИЗ X_norm:
        density = (1 / (sigma * КОРЕНЬ(2 * ПИ))) * ЭКСПОНЕНТА(-((x - mu)^2) / (2 * sigma^2))
        ДОБАВИТЬ density В Y_norm
    ПОСТРОИТЬ непрерывный линейный график (X_norm, Y_norm)

// 4. ПУАССОН
массив_lambda = [1, 5, 10]
ДЛЯ КАЖДОГО lambda ИЗ массив_lambda:
    max_k = ОКРУГЛИТЬ ВВЕРХ(lambda + 4 * КОРЕНЬ(lambda)) // Эмпирическая граница хвоста
    X_pois = ЦЕЛОЧИСЛЕННЫЙ МАССИВ ОТ 0 ДО max_k
    Y_pois = ПУСТОЙ МАССИВ
    ДЛЯ КАЖДОГО k ИЗ X_pois:
        prob = (lambda^k * ЭКСПОНЕНТА(-lambda)) / факториал(k)
        ДОБАВИТЬ prob В Y_pois
    ПОСТРОИТЬ столбчатый график (X_pois, Y_pois)

// 5. ЭКСПОНЕНЦИАЛЬНОЕ
массив_lambda_эксп = [0.5, 1, 2]
ДЛЯ КАЖДОГО lambda ИЗ массив_lambda_эксп:
    X_exp = ЛИНЕЙНОЕ ПРОСТРАНСТВО ОТ 0 ДО (5 / lambda), ШАГ=1000 // Граница, где плотность почти 0
    Y_exp = lambda * ЭКСПОНЕНТА(-lambda * X_exp) // Поэлементная операция
    ПОСТРОИТЬ непрерывный линейный график (X_exp, Y_exp)
```

### 5. Размерности и формы данных
*   **Дискретные СВ (Бернулли, Биномиальное, Пуассон):** 
    *   Массив $X$: одномерный массив целых чисел (длины 2, $n+1$ и $M$ соответственно).
    *   Массив $Y$: одномерный массив дробных чисел той же длины, что и $X$.
    *   *Важно:* Ось X — значения $k$, Ось Y — Вероятность (от 0 до 1).
*   **Непрерывные СВ (Нормальное, Экспоненциальное):**
    *   Массив $X$: одномерный массив дробных чисел высокой плотности (например, длина 1000).
    *   Массив $Y$: одномерный массив дробных чисел той же длины.
    *   *Важно:* Ось X — значения $x$, Ось Y — Плотность (может превышать 1).

### 6. Типичные ошибки
*   **Математические:**
    *   Переполнение типа данных при вычислении факториала ($n!$) в биномиальном распределении при больших $n$. Для графиков берите $n \le 20$ или используйте вычисление через логарифмы.
    *   Использование $\sigma \le 0$ для нормального распределения или $\lambda \le 0$ для Пуассона/Экспоненциального.
*   **Связанные с построением графиков:**
    *   Соединение точек сплошной линией для дискретных распределений (Биномиальное, Пуассон). Дискретная СВ не может принимать значения между узлами, поэтому между столбцами вероятность равна 0. Используйте столбчатые графики (bar) или маркеры/вертикальные линии (stem).
    *   Слишком широкий или слишком узкий диапазон оси X. Для нормального распределения диапазон должен зависеть от $\sigma$ (например, $\pm 4\sigma$), иначе графики с разными параметрами будут выглядеть обрезанными или плоскими.
*   **Связанные с интерпретацией:**
    *   Ожидание, что площадь под столбчатым графиком или сумма высот столбцов на графике Пуассона будет больше 1. Сумма именно *вероятностей* (высот столбцов) должна быть строго равна 1.

### 7. Пример самопроверки
1.  **Проверка Бернулли:** Если $p = 0.3$, то массив вероятностей должен быть `[0.7, 0.3]`. Сумма равна 1.0.
2.  **Проверка Биномиального:** Если $n=2, p=0.5$, вероятности для $k=0, 1, 2$ должны быть `[0.25, 0.5, 0.25]`. Сумма равна 1.0.
3.  **Проверка Нормального:** Для $\mu=0, \sigma=1$ в точке $x=0$ плотность должна быть равна $\frac{1}{\sqrt{2\pi}} \approx 0.3989$.
4.  **Числовая проверка интеграла (для непрерывных):** Если вы просуммируете все значения $Y_{norm}$ и умножите на шаг сетки $\Delta x = x_{i+1} - x_i$, результат должен быть очень близок к 1.0 (например, 0.999). Это проверка того, что вы построили именно плотность, а не просто абстрактную функцию.

### 8. Вопросы для размышления
1.  *Почему график нормального распределения (ось Y) может достигать значений больше 1 (например, при очень маленьком $\sigma$), в то время как график Бернулли не может превысить 1?*
    > Подсказка: Вспомните разницу между вероятностью конкретного значения и плотностью вероятности, а также как связана площадь под кривой с шириной колокола.
2.  *Как меняется форма распределения Пуассона при увеличении $\lambda$ от 1 до 20?*
    > Подсказка: Обратите внимание на асимметрию. Где находится пик при малых $\lambda$ и куда смещается масса при больших?
3.  *Если мы строим экспоненциальное распределение, почему нет смысла строить его для $x < 0$? Как это отражено в формуле?*
    > Подсказка: Подумайте о физическом смысле этой величины (например, время до наступления события) и о значении $f(x)$ на отрицательной полуоси.
4.  *Что произойдет с биномиальным распределением при $p=0$ и $p=1$? Как это будет выглядеть на графике?*
    > Подсказка: Вычислите вероятность для $k=0$ и $k=n$ в этих крайних случаях (граничные условия).
