# 🧠 Мои решения заданий из курса «Математика для машинного обучения»

Репозиторий для хранения выполненных заданий по курсу. Цель — закрепить математические концепции через код на NumPy.

## 📚 Структура папок с уроками

Каждый урок — отдельная папка 📁 `lesson_XX` с двумя файлами:
* 📋 `theory.md` — теория и формулы из урока.
* 🐍 `solutions.ipynb` — код и решения заданий.

## 📚 Структура проекта

* 📁`data/` — Датасеты к урокам.
* 📁 `lessons/` — Задания по урокам.
  * 📁 `lesson_01/` — Векторы и операции.
  * 📁 `lesson_02/` — Матрицы и линейные преобразования.
  * 📁 `lesson_03/` — Собственные числа и SVD.
  * 📁 `lesson_04/` — Производные и градиенты.
  * 📁 `lesson_05/` — Цепное правило и backprop.
  * 📁 `lesson_06/` — Матричное дифференцирование.
  * 📁 `lesson_07/` — Вероятность с нуля.
  * 📁 `lesson_08/` — Ключевые распределения.
  * 📁 `lesson_09/` — MLE и MAP.
  * 📁 `lesson_10/` — Оптимизация.
  * 📁 `lesson_11/` — Теория информации.
  * 📁 `lesson_12/` — Математика трансформеров.
* 📁 `venv` — Виртуальное окружение
* 📄 `requirements.txt` — Зависимости Python.
